# Archived Lean Pool vendor records

The files in this directory document the temporary Lean Pool source staging
that preceded the native FormalOLP integrations. They are historical records,
not active source manifests or build inputs.

`lean-pool-vendor-manifest.tsv` is the immutable per-file manifest from the
vendor state recorded by commits `13018b2` and `157ec9f`. It records the Pool
revision `c8ddda0a64f21cb019720cdda48c94354d4091e7`, original/current hashes,
and the ten compatibility modifications present in that staging snapshot.
The current tree does not claim that those manifest paths exist.

The dated provenance and reuse-plan files preserve the original source audit,
closure counts, and licensing analysis. Current native integration status is
recorded in the top-level documentation instead.
